Was MCP Marketing tut

MCP Marketing ist ein privates Werkzeug. Es wird ausschließlich vom Verantwortlichen für seine eigenen Konten genutzt. Andere Personen melden sich nicht an.

Welche Daten verarbeitet werden

Nach der Anmeldung des Kontoinhabers liest MCP Marketing über die offiziellen Schnittstellen nur Daten der eigenen Konten:

  • YouTube: Titel, Beschreibung, Dauer und Statistiken der eigenen Videos sowie Kanalstatistiken (YouTube Data API, YouTube Analytics API)
  • Instagram und Facebook: Bildunterschriften und Statistiken der eigenen Beiträge, Stories und Anzeigen
  • TikTok: Titel, Beschreibung und Statistiken der eigenen Videos
  • Google Ads: Anzeigentexte und Statistiken der eigenen Kampagnen

Die Zugriffe sind auf Leserechte beschränkt. MCP Marketing veröffentlicht, ändert oder löscht nichts.

Speicherung und Weitergabe

Die Daten werden ausschließlich lokal auf dem Rechner des Verantwortlichen gespeichert. Sie werden nicht verkauft, nicht an Dritte weitergegeben und nicht für Werbung verwendet. Zugangstokens liegen ebenfalls nur lokal.

Google-Daten

Die Nutzung und Übertragung von Informationen, die MCP Marketing von Google-APIs erhält, hält sich an die Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

MCP Marketing nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.

Zugriff widerrufen und Daten löschen

Der Zugriff kann jederzeit widerrufen werden: bei Google unter myaccount.google.com/permissions, bei Facebook und Instagram in den Einstellungen unter "Apps und Websites", bei TikTok in den Einstellungen unter "Sicherheit". Die lokal gespeicherten Daten werden dann vom Verantwortlichen gelöscht. Anfragen zur Löschung gehen an die oben genannte E-Mail-Adresse.

Diese Website

Diese Seite wird über GitHub Pages bereitgestellt. Sie setzt keine Cookies und verwendet kein Tracking. GitHub kann beim Aufruf technische Daten wie die IP-Adresse verarbeiten, siehe die Datenschutzerklärung von GitHub.

English summary

MCP Marketing is a private tool used only by its operator for the operator's own accounts. It reads, with read-only permissions, data of the operator's own YouTube, Instagram, Facebook, TikTok and Google Ads accounts and stores it only locally on the operator's computer. No data is sold, shared with third parties or used for advertising. MCP Marketing's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
